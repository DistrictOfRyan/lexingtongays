## LEXINGTON GAYS Brand

### Style: Modern Geometric Deco
Clean, bold, trendy. Poiret One font gives Art Deco DNA but the white+pink palette keeps it fresh and Instagram-native.

### Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Background | `#0a0a0a` | All slides, blog, profiles |
| White | `#FFFFFF` | "LEXINGTON", "T" monogram, primary text, tagline |
| Neon Pink | `#FF1493` | "GAYS", "G" monogram, accent bar, links, highlights |
| Light Gray | `#cccccc` | Secondary text, descriptions |
| Gray | `#888888` | Muted text, timestamps |
| Dark Gray | `#555555` | Subtle dividers |

### Typography

| Element | Font | Weight | Size | Color |
|---------|------|--------|------|-------|
| "T" / "G" monogram | Poiret One | thickened (stroke 2.5px) | 180pt | White / Neon Pink |
| "LEXINGTON" / "GAYS" | Poiret One | thickened (stroke 1.2px) | 52pt | White / Neon Pink |
| Tagline | Segoe UI | Semibold (600) | 18pt | White |
| "THIS WEEK" | Poiret One | thickened | 50pt | Neon Pink |
| Date range | Segoe UI Light | 300 | 34pt | White |
| Day headers | Poiret One | thickened | 44pt | Day accent color |
| Event names | Segoe UI Bold | 700 | 30-32pt | White |
| Event time/date | Segoe UI | 400 | 21-22pt | Gray |
| Event venue | Segoe UI | 400 | 21-22pt | Neon Pink |
| Descriptions | Segoe UI | 400 | 18-19pt | Light Gray |
| Brand footer | Poiret One | thickened | 20pt | White + Neon Pink |

### Decorative Elements

- **Accent bar**: 3px neon pink line under "LEXINGTON GAYS" text
- **No top/bottom colored bars** (that's the HHHH brand)
- **No diamond ornaments** (that's the HHHH brand)
- **Rainbow stripe**: 3px six-color rainbow — used sparingly on day slides only

## Shared Rules

- **Anonymity**: Operator's name never appears anywhere on public site or social
- **Tone**: Casual, warm, sassy, community-focused, authentically human
- **No**: em dashes, corporate speak, AI-tell words
- **Cross-promote**: When a signature event is added, Lexington Gays mentions it as featured event; signature event posts say "via @lexingtongays" or "Follow @lexingtongays for more events"

## Posting Schedule

- **Lexington Gays weekly carousel**: Generated Sunday evening, posted Monday morning
- **Signature event** (when added): cadence per its frequency (monthly = 3 weeks before + 1 week + 2 days + morning-of; annual = different cadence)
